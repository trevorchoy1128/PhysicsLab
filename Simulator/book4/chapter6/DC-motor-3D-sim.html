📐 馬達力矩公式

$$\tau = B\,I\,L\,\cos\theta$$
換向器每半圈反轉電流，使力矩恆為正（已整流）；轉速由力矩與摩擦、負載、反電動勢共同決定。

🔄 換向器 vs 滑環（匯電環）

A換向器 + DC：分裂環每半圈機械式反轉線圈電流，力矩恆同向 → 連續轉動。
B滑環 + DC：連續環讓電流方向固定不反轉，過 90° 後力矩反向 → 線圈只能來回擺動，停在平衡點，無法連續轉動。
C滑環 + AC：電源在外部每半圈同步反相，取代換向器的機械反相 → 恢復連續轉動（此為理想同步化示意）。

📖 工作原理

1磁力 F = B·I·L：通電導線在磁場中受力，力的方向與電流、磁場互相垂直。
2弗萊明左手定則：食指 = 磁場 (B)、中指 = 電流 (I)、拇指 = 受力 / 運動方向。
3換向器 + 碳刷：每半圈反轉線圈電流，使力矩始終同向（因此力矩圖恆為正）。
4死點 (90° / 270°)：力矩瞬間為 0，靠轉動慣量帶過。
5反電動勢：轉速上升使反電動勢增大、電流下降，最終達到穩態轉速；增加負載則轉速下降、電流回升。
