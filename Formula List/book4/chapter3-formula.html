分壓器 Potential divider

$$V_{out} = \left(\frac{R_1}{R_1 + R_2}\right) \varepsilon$$
$$V_{out} = \left(\frac{R_1}{R_1 + R_2}\right) \varepsilon$$
均勻電阻線變形公式： $$V_{out} = \left(\frac{l_1}{l_1 + l_2}\right) \varepsilon$$
Derived formula for uniform wire: $$V_{out} = \left(\frac{l_1}{l_1 + l_2}\right) \varepsilon$$
定義： 兩個電阻器根據電阻比來「分配」電動勢。這種接駁方式稱為分壓器。
Definition: Two resistors 'divide' the e.m.f. according to the ratio of their resistance. This connection is called a potential divider.
📐 變數與單位解釋 (含變形公式) 📐 Variables and Units (Including derived equations)
  • $V_{out}$
    ：輸出電壓，單位：伏特 ($\text{V}$) : output voltage, unit: volt ($\text{V}$)
  • $\varepsilon$
    ：電源的電動勢，單位：伏特 ($\text{V}$) : e.m.f. of source, unit: volt ($\text{V}$)
  • $R_1, R_2$
    ：電阻，單位：歐姆 ($\Omega$) : resistance, unit: ohm ($\Omega$)
  • $l_1, l_2$
    ：導線長度，單位：米 ($\text{m}$) 或 厘米 ($\text{cm}$) : length of wire, unit: meter ($\text{m}$) or centimeter ($\text{cm}$)
✏️ 應用範例 ✏️ Example
題目：一條均勻電阻線 PQ 連接到 $1.5\ \text{V}$ 電池組。PQ 長 $30\ \text{cm}$。滑動觸頭 S 可沿 PQ 移動。開始時，PS 長 $20\ \text{cm}$。求 X 和 Y 之間的電壓 $V$。 Question: A uniform resistance wire PQ is connected to a $1.5\ \text{V}$ battery. It is $30\ \text{cm}$ long. S is a sliding contact which can move along PQ. Initially PS is $20\ \text{cm}$ long. Find the voltage $V$ across X and Y.
題解：
Solution:
$$V = \frac{SQ}{PQ} \times \varepsilon = \frac{30 - 20}{30} \times 1.5 = 0.5\ \text{V}$$
📝 隨堂練習 📝 Practice
題目：均勻的電阻線 PQ 連接到 $6\ \text{V}$ 電池組。滑動觸頭 S 可沿 PQ 移動。如果 $PQ = 100\ \text{cm}$，而 $V_{out} = 3\ \text{V}$，求 $PS$ 的長度。 Question: A uniform resistance wire PQ is connected to a $6\ \text{V}$ battery. S is a sliding contact which can move along PQ. If $PQ = 100\ \text{cm}$ and $V_{out} = 3\ \text{V}$, find the length of $PS$.
題解：
Solution:
$$3 = \left(\frac{PS}{100}\right) \times 6 \implies PS = 50\ \text{cm}$$

電阻器網絡 Resistor network

$$\text{串聯：} R_{eq} = R_1 + R_2 + ... + R_n$$ $$\text{並聯：} \frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n}$$
$$\text{In series: } R_{eq} = R_1 + R_2 + ... + R_n$$ $$\text{In parallel: } \frac{1}{R_{eq}} = \frac{1}{R_1} + \frac{1}{R_2} + ... + \frac{1}{R_n}$$
重畫複雜電路技巧：
1. 導線可加長或縮短，如果兩個連結點以一條導線連接，則可合併為一個連結點。
2. 重新整理導線，把電阻器水平或垂直放置。連接點可沿導線移動至另一位置。
Skill for redrawing complicated networks:
1. Wires can be lengthened or shortened. Two junctions connected by a wire can be joined as one.
2. Rearrange the wires to place the resistors either horizontally or vertically. You can move a junction along a wire.
📐 變數與單位解釋 (含變形公式) 📐 Variables and Units (Including derived equations)
  • $R_{eq}$
    ：等效電阻，單位：歐姆 ($\Omega$) : equivalent resistance, unit: ohm ($\Omega$)
  • $R$
    ：個別電阻，單位：歐姆 ($\Omega$) : individual resistance, unit: ohm ($\Omega$)
✏️ 應用範例 ✏️ Example
題目：可變電阻 $r$ 與四個相同的電阻器連接（等效為 $R_{eq}$）。當 $r = 24\ \Omega$，總等效電阻 $R_{XY}$ 是 $15\ \Omega$。當 $R_{XY}$ 是 $8\ \Omega$，$r$ 是多少？ Question: Variable resistor $r$ is connected with four identical resistors (equivalent to $R_{eq}$). When $r = 24\ \Omega$, the total equivalent resistance $R_{XY}$ is $15\ \Omega$. Find $r$ when $R_{XY}$ is $8\ \Omega$.
題解：
電阻器可用一個電阻為 $R_{eq}$ 的電阻器取代。
當 $r = 24\ \Omega$， $$\frac{1}{24} + \frac{1}{R_{eq}} = \frac{1}{15} \implies R_{eq} = 40\ \Omega$$ 當 $R_{XY} = 8\ \Omega$， $$\frac{1}{r} + \frac{1}{40} = \frac{1}{8} \implies r = 10\ \Omega$$
Solution:
Resistors can be replaced by a resistor of resistance $R_{eq}$.
When $r = 24\ \Omega$, $$\frac{1}{24} + \frac{1}{R_{eq}} = \frac{1}{15} \implies R_{eq} = 40\ \Omega$$ When $R_{XY} = 8\ \Omega$, $$\frac{1}{r} + \frac{1}{40} = \frac{1}{8} \implies r = 10\ \Omega$$
📝 隨堂練習 📝 Practice
題目：求 X 和 Y 兩端的等效電阻 $R_{eq}$。三個電阻器並聯，每個電阻器的電阻是 $3\ \Omega$。 Question: Find the equivalent resistance $R_{eq}$ across X and Y. Three resistors are connected in parallel, each has a resistance of $3\ \Omega$.
題解：
Solution:
$$\frac{1}{R_{eq}} = \frac{1}{3} + \frac{1}{3} + \frac{1}{3} = 1 \implies R_{eq} = 1\ \Omega$$

電源的內電阻 Internal resistance of power sources

$$\varepsilon = V + I r$$
$$\varepsilon = V + I r$$
變形公式：
端電壓：$$V = \varepsilon - I r$$
Derived formula:
Terminal voltage: $$V = \varepsilon - I r$$
📐 變數與單位解釋 (含變形公式) 📐 Variables and Units (Including derived equations)
  • $\varepsilon$
    ：電池的電動勢，單位：伏特 ($\text{V}$) : e.m.f. of battery, unit: volt ($\text{V}$)
  • $V$
    ：端電壓（或伏特計讀數），單位：伏特 ($\text{V}$) : terminal voltage (or voltmeter reading), unit: volt ($\text{V}$)
  • $I$
    ：流過電池組的電流，單位：安培 ($\text{A}$) : current through battery, unit: ampere ($\text{A}$)
  • $r$
    ：電源的內電阻，單位：歐姆 ($\Omega$) : internal resistance of source, unit: ohm ($\Omega$)
✏️ 應用範例 ✏️ Example
題目：奕希利用電路找出電動勢為 $\varepsilon$ 的電池組的內電阻 $r$。當 $I = 2\ \text{A}$ 時，$V = 2\ \text{V}$；當 $I = 0\ \text{A}$ 時，$V = 3\ \text{V}$。求 $\varepsilon$ 和 $r$。 Question: Willy uses a circuit to find the internal resistance $r$ of a battery of e.m.f. $\varepsilon$. When $I = 2\ \text{A}$, $V = 2\ \text{V}$; when $I = 0\ \text{A}$, $V = 3\ \text{V}$. Find $\varepsilon$ and $r$.
題解：
$$\varepsilon = V + I r \implies V = (-r)I + \varepsilon$$ 當 $I = 0\ \text{A}$ 時，$V = \varepsilon \implies \varepsilon = 3\ \text{V}$
代入 $V=2, I=2$：
$$2 = 3 - 2r \implies r = 0.5\ \Omega$$
Solution:
$$\varepsilon = V + I r \implies V = (-r)I + \varepsilon$$ When $I = 0\ \text{A}$, $V = \varepsilon \implies \varepsilon = 3\ \text{V}$
Substitute $V=2, I=2$:
$$2 = 3 - 2r \implies r = 0.5\ \Omega$$
📝 隨堂練習 📝 Practice
題目：電池組的電動勢 $\varepsilon$ 是 $3\ \text{V}$，內電阻 $r$ 是 $0.5\ \Omega$。它連接到一個 $4.5\ \Omega$ 的電阻器 $R$。求端電壓 $V$。 Question: A battery has an e.m.f. $\varepsilon$ of $3\ \text{V}$ and internal resistance $r$ of $0.5\ \Omega$. It is connected to a $4.5\ \Omega$ resistor $R$. Find the terminal voltage $V$.
題解：
Solution:
$$I = \frac{\varepsilon}{R + r} = \frac{3}{4.5 + 0.5} = 0.6\ \text{A}$$ $$V = I R = 0.6 \times 4.5 = 2.7\ \text{V}$$

關於實際的安培計和伏特計，下列哪項敘述是正確的？ Which of the following statements about practical ammeters and voltmeters is correct?
良好安培計的內電阻非常高 A good ammeter has a very high internal resistance
良好伏特計的內電阻非常低 A good voltmeter has a very low internal resistance
理想的伏特計電阻為零 An ideal voltmeter has zero resistance
良好安培計的內電阻非常低，而良好伏特計的內電阻非常高 A good ammeter has a very low internal resistance, and a good voltmeter has a very high internal resistance
✅ 正確！安培計串聯在電路中，內電阻要低；伏特計並聯在元件上，內電阻要高。 ✅ Correct! An ammeter is connected in series, so its resistance must be low; a voltmeter is connected in parallel, so its resistance must be high.
